# Fork release 1.3.1

Released: 2026-09-21

This is a maintenance release in the independent TonChaiya fork sequence. The imported upstream baseline remains `pedro-quiterio/PoeAncientsPriceHelper` 3.7.1; upstream version numbers are not reused.

## Delivered

- Reliable Edit/Done interaction with focus restoration and selectable, replaceable Min/Max values.
- Dedicated checkbox hit areas with a compact visual template that does not overlap modifier text.
- A title-only drag surface, leaving Edit and Close as independent controls.
- Correct handling of the PoE 2 `Requires: Level ...` clipboard form as an item property.
- Per-listing links to the anonymous official Path of Exile Trade result for the selected league and returned search ID.

## Safety boundary

The helper responds only to the player's normal `Ctrl+C` while the real PoE 2 window is foreground. It does not modify or inspect game files or memory, inject code, capture packets, synthesize input, read cookies/tokens, contact sellers, or automate trades. Opening a listing launches a normal official Trade URL in the user's browser. It has no external software auto-update path.
