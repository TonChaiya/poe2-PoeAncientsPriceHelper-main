- Structured PoE 2 item parsing with requirements, properties, states, headers, current values, and roll ranges kept separate.
- Evidence-ordered Trade family resolution across all published metadata families; ambiguous matches are never guessed.

## Safety boundary

The helper responds only to the player's normal `Ctrl+C` while the real PoE 2 window is foreground. It does not modify or inspect game files or memory, inject code, capture packets, synthesize input, read cookies/tokens, contact sellers, or automate trades. It has no external software auto-update path.
