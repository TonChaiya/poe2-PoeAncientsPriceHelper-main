## Features

- Manual focused-game `Ctrl+C` opens an integrated detailed equipment filter window.
- Unique stat-template mapping avoids guessing unknown or ambiguous modifiers.
- Anonymous selected-league Trade search/fetch with dynamic rate-limit handling, bounded bodies, cancellation, and stale-result protection.
- Price estimate includes credible low, interquartile range, median, match/sample counts, and confidence.
- Root `overlay/` module provides isolated code, tests, and maintenance documentation.
