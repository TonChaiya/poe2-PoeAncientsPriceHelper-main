# Release 1.0.0

Date: 2026-09-20

First independent fork release, based on upstream `pedro-quiterio/PoeAncientsPriceHelper` version 3.7.1.

## Features

- Full-screen ground-loot OCR and non-overlapping price badges.
- Stack quantity totals and broad exchange/stash market coverage.
- Dynamic league selection with live discovery, atomic local cache, and offline fallback.
- Price reload for the exact selected league.
- Deterministic Uncut Skill/Spirit/Support Gem pricing by type and level, including `Skill Level N` panel text.
- Foreground pause, bounded OCR cadence, resolution caching, and limited network concurrency.
- External software auto-update removed; releases are owner-built and manually installed.
- Self-contained x64 Windows installer.

Verification results and installer SHA-256 are recorded in the release commit/hosting release notes after packaging.
