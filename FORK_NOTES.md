# Fork provenance

This project is an independent continuation of [pedro-quiterio/PoeAncientsPriceHelper](https://github.com/pedro-quiterio/PoeAncientsPriceHelper). The local code line used as the starting point was upstream version **3.7.1**. The upstream project and its authors remain credited under the original license.

Fork releases use their own version sequence beginning at **1.0.0**. They do not imply compatibility with, or automatic updates from, upstream versions.

## What this fork adds

- Full-screen PoE 2 ground-label OCR instead of requiring a fixed price panel.
- A price badge placed after each detected item label, including stack totals.
- Dynamic PoE 2 league discovery from poe.ninja with cache and offline fallback.
- Selected-league price downloads across exchange and stash item categories.
- Exact Uncut Skill, Spirit, and Support Gem pricing by type and level.
- Reduced scan cadence, cached name resolution, foreground gating, and bounded network concurrency.
- A self-contained Windows installer and fork-owned documentation.
- No Velopack, GitHub release poll, or other external software auto-update channel.
